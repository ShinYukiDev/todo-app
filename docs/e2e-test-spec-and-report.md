## 2. テスト方針

コンソール対話を入力ストリームで再現し、実行結果のメッセージと最終状態を確認する。  
正常系と異常系（入力バリデーション）をE2Eで検証する。

## 3. 前提条件

1. .NET 10 SDK がインストール済み
2. 依存パッケージ復元済み（`dotnet restore`）
3. 実行前にDBファイルを初期化する
   - `src\TodoApp\bin\Debug\net10.0\todo.db` を削除

## 4. 実行コマンド

```powershell
# 正常系シナリオ
$db = "src\TodoApp\bin\Debug\net10.0\todo.db"
if (Test-Path $db) { Remove-Item $db -Force }
$input = @"
2
タスクA
2
タスクB
1
3
1
タスクA更新
5
2

"@
$input | dotnet run --project src\TodoApp\TodoApp.csproj

# 異常系シナリオ
if (Test-Path $db) { Remove-Item $db -Force }
$input = @"

正常タスク

999
更新

999

999

"@
$input | dotnet run --project src\TodoApp\TodoApp.csproj
```
